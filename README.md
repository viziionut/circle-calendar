
# Circle Calendar Beta 0.3

Functional browser beta for friend testing.

## Functions included
- Pre-login Bro's / Girls' experience selector
- Local account creation and login
- Profile image and username
- Bro's / Girls' themes
- Create, edit and delete events
- RSVP: going / maybe
- Event cover image
- Group creation and join by invitation code
- Holiday/location availability
- Local group chat
- Photo/video upload previews
- Feedback form
- Local persistence with browser localStorage

## Important limitation
This beta stores data separately in each browser. It is useful for testing the
interface and functions, but it does not yet synchronize friends with one another.

Real multi-user synchronization requires Supabase (Auth, Database, Storage, Realtime).

## Deploy
Upload the extracted folder to Vercel. Framework: Next.js.
